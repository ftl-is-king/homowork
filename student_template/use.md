# 作业提交使用指南 (use.md)

---

## 提交步骤

### 1. 准备代码
1. 在个人 GitHub 账号下新建公开（Public）仓库。
2. 将代码按题号命名上传（如 `1_main.c`、`2_main.c`）。
3. 确保每个代码文件**前三行**注释包含学号、邮箱和姓名：
   ```c
   // 202401010001
   // student@example.com
   // 张三
   ```

### 2. 提交 Issue 审批
1. 进入作业审批仓库：[ftl-is-king/homowork/issues](https://github.com/ftl-is-king/homowork/issues)。
2. 点击 **New Issue**。
3. 填写两栏内容：
   - **Title（标题栏）**：填 `[作业提交] 学号 - 姓名`（例如 `[作业提交] 202401010001 - 张三`）
   - **Leave a comment（正文栏）**：直接粘贴你的代码仓库链接（例如 `https://github.com/zhangsan/my-c-hw`）
4. 点击 **Submit new issue**。

### 3. 查看成绩
等待 1~2 分钟，机器人会自动在你的 Issue 评论区回复成绩单，并将成绩登记入库。

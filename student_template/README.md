# C 语言作业代码仓库模板

本仓库为学生作业提交模板工程。

## 文件命名规范
每个作业代码请按照题目编号命名：
- 第 1 题：`1_main.c` 或 `1_xxx.c`
- 第 2 题：`2_main.c` 或 `2_xxx.c`
- 第 3 题：`3_main.c` 或 `3_xxx.c`
- 其余题目以此类推...

## 代码头部注释规范（系统据此识别学号姓名）
每个 `.c` 文件的**前两行**必须按如下格式书写注释（以 `//` 开头）：

```c
// 202401010001
// 张三
```

## 提交作业方式
在 [ftl-is-king/homowork/issues](https://github.com/ftl-is-king/homowork/issues) 点击 **New Issue**：
- **标题（Title）**：直接保留默认的 `[作业提交]` 即可（系统会自动从代码提取学号姓名并重命名）
- **正文（Body）**：直接粘贴你本代码仓库的公开 GitHub 网址（例如 `https://github.com/your-username/my-c-hw`）

## 修改代码后如何重新评测？
在个人仓库修改代码并 push 后：
- 直接在原 Issue 楼下评论任意一句话（如“申请重测”），机器人会在几秒内拉取最新代码重测，并在楼下回复一条全新的独立成绩报告！
- **历史最高分保护**：任何题目的得分都是只增不减，系统自动保留单题最高成绩。

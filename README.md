# C 语言作业自动化审批与评测系统 (学生端使用指引)

欢迎来到 C 语言作业提交与自动评测平台！学生在此仓库通过发 Issue 提交自己的作业仓库链接，系统在后台自动拉取代码、编译测试、综合打分，并在您的 Issue 下方自动回复详细成绩报告。

---

## 📝 作业提交规范（极简提交）

进入 **[Issues 页面](https://github.com/ftl-is-king/homowork/issues)**，点击 **New Issue**：

页面仅有 **标题 (Title)** 与 **正文 (Leave a comment)** 两栏，**无需手动输入学号和姓名**：

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 标题 (Title)：                                                              │
│ [作业提交]                                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 正文 (Leave a comment)：                                                    │
│ https://github.com/zhangsan/c-homework                                      │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **标题 (Title)**：直接保留默认的 `[作业提交]` 即可。机器人评测完毕后，会将标题自动更新为 `[作业评测已完成]`，**绝不包含任何个人学号与姓名**。
2. **正文 (Leave a comment)**：**直接粘贴你存放作业代码的公开（Public）GitHub 仓库网址**。

---

## 💻 学生代码文件组织与注释规范

机器人克隆您的仓库后，将依据以下规范识别身份与评测：

### 1. 文件命名规范
必须以 **题目序号** 开头：
- 第 1 题：`1_main.c` 或 `1_xxx.c`（单题作业亦可命名为 `main.c`）
- 第 2 题：`2_main.c` 或 `2_xxx.c`
- 第 3 题：`3_main.c` 或 `3_xxx.c`
- 后续题目以此类推...

### 2. 代码头部注释规范（仅需前 2 行，无需邮箱）
每个 `.c` 文件的**前两行**必须以 `//` 注释学号和姓名，**完全不需要编写邮箱**：

```c
// 202401010001
// 张三

#include <stdio.h>

int main() {
    int n;
    if (scanf("%d", &n) == 1) {
        printf("%d,%d\n", n + 10, n + 10);
    }
    return 0;
}
```

## 🔄 代码修改后，如何重新评测？

如果测试点未全部通过，或者你想优化算法提高成绩，在个人仓库中修改代码并 `git push` 后：

### 极简重测方式（直接在原 Issue 楼下留言）：
1. 打开你之前提交的 Issue，直接在最下方的评论框输入任意消息（例如：`申请重测` 或 `已修改代码`），点击 **Comment**；
2. 机器人会在几秒内拉取你的最新代码重新测试，并在下方**回复一条全新的独立成绩报告**，形成清晰完整的每一次提交历史轨迹！

> 💡 **最高分保护机制**：无论重新评测多少次产生多少条独立报告，系统私有库中均**只增不减，永久保留您每道题目的历史最高成绩**，无惧多次尝试与性能调优！
